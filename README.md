# 微聊 APK

一个参考 WeChatBot_Web 架构重写的原生 Android 聊天模拟器。它不是 WebView，而是用原生 View 实现聊天界面、头像背景、人设、记忆和上下文维护。

## 功能特性

- **流式聊天**：边生成边显示，支持停止生成
- **人设即会话**：每个聊天对象都有独立的人格、头像、消息、记忆
- **隐藏记忆**：可设置不会展示在聊天界面的长期背景
- **临时记忆总结**：对话积累后可手动或自动整理为长期记忆
- **上下文维护**：按设置保留最近若干轮对话参与回复
- **时间注入**：可开关当前时间上下文
- **气泡分割**：支持用反斜线 `\` 拆分多条聊天气泡
- **消息控制**：支持 AI 撤回标记；拍一拍入口已取消
- **头像与背景**：支持设置我的头像、聊天对象头像和聊天背景
- **微信式界面**：顶部栏、消息气泡、底部输入栏、记忆面板、人设列表

## 快速开始

1. 从 [Releases](../../releases) 下载最新 APK
2. 安装并打开应用
3. 直接输入消息聊天
4. 点击左上角可切换或新增聊天对象
5. 点击右上角记忆按钮可整理或清理记忆
6. 点击右上角更多按钮可设置头像、背景、上下文和自动整理

## 技术架构

- **OkHttp**：流式请求
- **本地 JSON 状态**：保存人设、消息、记忆与设置
- **Prompt Builder**：人格 + 隐藏记忆 + 长期记忆 + 时间 + 最近上下文
- **原生 View UI**：单 Activity 程序化布局，无 Compose 依赖
- **MeshGradientView**：Canvas 实现动态渐变背景

## 构建

```bash
gradle assembleDebug
```

APK 输出路径：`app/build/outputs/apk/debug/app-debug.apk`
